Kondor Browser 0.3.0 is the biggest update so far: a password manager, extensions, new tab layouts and a lot of polish. Under the hood, Kondor is now written in Python, which makes it easier to work on. Your profile, bookmarks and history carry over as they are.

## Tabs your way

- **Four tab styles.** Floating tabs are the new default. You can also put the tabs below the address bar, in a side bar, or keep the classic look. Pick one in Settings → General → Appearance.
- **Vertical tabs in a side bar**, which can shrink to icons only when you want more room for the page.
- Dragging a tab now follows the pointer and makes room for it as you move.

## Passwords

- **Kondor remembers your passwords** in KWallet and fills them in when you come back, also on sign-in pages that ask for the user name first (like Google).
- **Import** your passwords from Chrome, Firefox, Bitwarden, 1Password or any CSV file.
- Add a login by hand, search all your saved passwords, and copy a user name or password right from the address bar.

## Extensions

- **Install extensions** from the Kondor catalog or from a file. The first ones: Dark Mode, Video Speed Controller, Cookie Banner Blocker, Skip Sponsors, YouTube Dislike Counts, JSON Viewer, User Styles, Clean Links and Mouse Gestures.
- **User scripts**: open a `.user.js` page to install it, and manage it like any other extension.
- An Extensions panel that stays tidy with many extensions, and a toolbar where you pin the ones you use most.

## Bookmarks

- A **Bookmarks panel** on the toolbar, with search, your recent bookmarks and your folders.
- The bookmarks bar gets an overflow menu, drag and drop, and folder actions.

## More

- **Remote control for automation tools and AI agents** (off by default, only for programs on your own computer).
- The main menu is regrouped and shows the keyboard shortcuts.
- Kondor is now available as a **Flatpak** from its own repository, with updates in Discover.

## Fixes

- The page no longer turns black after you minimize and restore the window.
- Site icons are saved again, so bookmarks and the New Tab page show them instead of a globe.
- The window no longer freezes for a moment when a download finishes.
- Ctrl+D opens the bookmark popup ready to type, and Esc closes it.
- Confirmation dialogs no longer show each button twice.
- Better screen reader support for icon-only buttons and Settings pages.
- Many smaller fixes to icons, colors and spacing so everything looks at home in Breeze.
